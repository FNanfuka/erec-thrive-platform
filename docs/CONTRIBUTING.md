# Contributing to EREC THRIVE Intelligence System

Thank you for your interest in contributing to EREC's open-source climate-health platform. We welcome contributions from data scientists, public health practitioners, software developers, and community practitioners.

## Ways to Contribute

- **Bug reports** — open an issue describing the problem
- **Feature requests** — open an issue with your proposal
- **Code contributions** — submit a pull request
- **Documentation** — improve guides and API docs
- **Data** — contribute open datasets relevant to Uganda's climate-health landscape
- **Translation** — help localise the dashboard (Luganda, Langi, Swahili)

## Development Setup

```bash
git clone https://github.com/FNanfuka/erec-thrive-platform.git
cd erec-thrive-platform
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Code Standards

- Follow PEP 8 style guidelines
- Add docstrings to all functions and classes
- Write tests for new functionality in `tests/`
- Run `black src/` before submitting PRs

## Principles

This project follows [UNICEF's Principles for Digital Development](https://digitalprinciples.org/):
- Design with the user
- Understand the ecosystem
- Design for scale
- Build for sustainability
- Be data driven
- Use open standards and open source
- Reuse and improve
- Be collaborative

## Code of Conduct

We are committed to a welcoming and inclusive environment. All contributors must treat each other with respect, regardless of background, gender, disability, nationality, or any other characteristic.
